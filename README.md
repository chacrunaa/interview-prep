# interview-prep

Поиск работы Go/JS-разработчиком: резюме под вакансии, ответы на формы, доска откликов и подготовка к собесам.

## Как пользоваться

**Что нового на Hirify:** `/career hirify scan`. Читает сохранённые фиды, отсеивает неподходящее по карточкам (бесплатно), читает целиком только шортлист и складывает его в `hirify/scan.md`. Заодно сверяет доску с реальными откликами на Hirify. Контакты не раскрывает и не откликается - это только по твоему «да».

**Отклик на вакансию**
1. Вставь текст вакансии в `<направление>/inbox.md` (или прямо в сообщение). Для `hirify` не нужно: вакансия берётся по `vacancy_id` из `scan.md`.
2. `/career hh new`: получишь карточку, резюме и строку на доске.
3. Отправил или получил ответ: `/career status x5 скрининг` или свободной фразой: «x5 позвали на тех 2 октября».

**Вопросы HR-формы или бота:** вставь вопросы в `inbox.md`, затем `/career hirify answers <slug>`. Готовый к копированию текст - в `answers.txt` папки вакансии.

**Подготовка:** `/teach-go lesson | drill | mock | review | status`. На созвоне: `/teach-go live qa` или `live code`.

Направление можно не указывать: скилл определит его по источнику и скажет, какое выбрал.

## Направления

| Папка | Что |
|---|---|
| `hh/` | RU-рынок через hh.ru |
| `hirify/` | компании, ушедшие из РФ: Кипр, Средняя Азия и т.п., вакансии en/ru |
| `linkedin/` | профиль LinkedIn и запад (EU/US) |

Внутри каждого направления одинаково:

| | |
|---|---|
| `CANON.md` | правила резюме: объём, секции, формат |
| `master/` | эталонное резюме |
| `fish/` | рыба: досочинённые буллеты, паттерны, сюжет по местам работы, заготовки ответов. Без названий компаний, только слоты `[S1]`-`[S3]` |
| `inbox.md` | сюда кладёшь вакансию или вопросы |
| `scan.md` | лента триажа после `/career hirify scan`: шортлист, что отсеяно, что уже отправлено. Только `hirify/` |
| `pipeline/` | `BOARD.md` - доска откликов; одна папка на вакансию: `card.md` + `cv-*.txt`, `letter.txt`, `answers.txt`; `archive/` - закрытые |

У `linkedin/` дополнительно: `profile/` (профиль по полям), `inbound.md` (входящие от рекрутеров), `experiments.md` (что меняли в профиле и что это дало), `notes/`.

## Главное правило

Каждый отклик - проверка гипотезы: «8 лет вместо 5», «локация Лимасол», «тайтл Senior». Гипотеза записана в `card.md` и на доске. Неизменен только стек: Go / JS с любыми фреймворками.
