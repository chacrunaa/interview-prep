# go-react-fintech - профиль вакансии

Источник: `vacancies/hh/for-scan-vacancy.txt` (Senior + (эксперт) Java Developer (Go / React), FinTech, РФ, удалёнка).
Обработано: 2026-09-29 (`sync-resume`, русская версия резюме)

Роль по тексту вакансии: серверная разработка на Java Spring плюс участие либо во фронтенде
(React/TypeScript), либо в бэкенде на Go. Акцент на реляционные БД, REST API, тестирование,
серверную архитектуру, Docker/Kubernetes и CI/CD в финтех-продуктах.

- Домен: `#fintech`
- Тип бизнеса: `#b2b` (по тексту не определяется однозначно; финтех-продукт, вероятнее b2b/b2b2c)
- Тип системы: `#billing` `#payment-gateway` (финансовые операции как ядро продукта)
- Тип компании: `#avg-product` / `#enterprise` (требование "7+ лет" и "эксперт" + широкий стек
  Java+Go+React - характерно для устоявшейся продуктовой или интеграторской команды)

## Ключевое решение прогона

Java/Spring в резюме не добавлялся - прямое указание пользователя: Java он не знает.
Резюме собрано как чисто Go-бэкендное и целится во вторую ветку требования
("коммерческий опыт с Go ИЛИ React + TypeScript и готовность освоить второе направление"):
сильный Go + финтех-домен + фронтенд, вместо слабой имитации Java-экспертизы.
Риск отсева по основному требованию осознан и принят.

## Закрыто резюме как есть

- Высшее образование в ИТ - СПбГУТ им. Бонч-Бруевича, 2022
- Коммерческий Go с июл 2021, три компании
- PostgreSQL - редизайн схем, индексы, транзакции, N+1, keyset-пагинация, линтинг миграций
- Unit- и интеграционные тесты - внедрение практики, покрытие критичной логики 0% -> 95%
- REST API и серверная архитектура - REST + gRPC/Protobuf, 14 микросервисов
- Docker, Kubernetes, CI/CD (GitLab CI)
- Финтех - платёжный домен Syndicate Group, идемпотентность критичных операций

## Незакрытые требования и чем закрыты

- **Финтех-глубина** - на весь финтех в резюме была одна строка. Закрыто новым fish-bullet #17
  (деньги в минорных единицах/decimal, двойная запись в реестре, ежедневная сверка с внешним
  провайдером, неизменяемый журнал для аудита) и переиспользованием #14 (saga + outbox).
  Привязано к платёжному домену Syndicate Group.
- **Интеграционное тестирование** - названо отдельным требованием. Закрыто новым fish-bullet
  #18 (testcontainers с реальными PostgreSQL/Redis, прогон миграций в тесте, тесты как гейт
  в CI). Привязано к Carprice с продолжением на Syndicate.
- **Серверная архитектура как термин** - переиспользован fish-bullet #15 (bounded contexts,
  слои domain/application/infrastructure, порты и адаптеры, SOLID). Привязано к Syndicate.
- **React + TypeScript** - переиспользован fish-bullet #8 (GraphQL на gqlgen + фронтенд на
  React/TS с Apollo Client). Привязано к Nedra Digital - устойчивая привязка с прогона nodi.
- **Базовый DevOps** - переиспользован fish-bullet #11 (managed K8s, S3, managed PostgreSQL,
  Terraform, деплой с миграциями и health-гейтом). Привязано к Syndicate.
- **Готовность освоить второе направление** - закрыто фактом, а не декларацией:
  переиспользован fish-bullet #7 (перевод легаси Express/NestJS на Go доменами).

## Не закрыто сознательно

- **Экспертное знание Java Spring** - основное требование вакансии. Не добавляется по прямому
  указанию пользователя: Java он не знает, а это проверяется первым же техническим вопросом.
- **7+ лет опыта разработки** - трудовая история начинается с июл 2021 (~5 лет 2 мес).
  Закрывается только добавлением реальных ранних мест работы в `actual-template-resume.txt`;
  досочинять работодателей запрещено жёстким ограничением скилла.
