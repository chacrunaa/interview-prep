recover — шпаргалка

Суть: recover() останавливает панику и возвращает её значение. Работает только напрямую в defer-функции и только в своей горутине. После него функция завершается, а не продолжается.

Правила

  • Вне defer возвращает nil.
  • Паника в любой горутине без своей защиты роняет всё приложение: defer recover в начале каждой горутины.
  • Ошибку наружу через именованный результат: err = fmt.Errorf(...).
  • Не поймать (вне банка): fatal error (concurrent map writes, OOM, переполнение стека), os.Exit.

Где ставят

  • Recovery middleware HTTP-сервера (500 вместо падения).
  • Верх горутины-воркера и демона.
  • Не вместо error: panic/recover как try/catch это анти-паттерн.
go func() {
    defer func() {
        if r := recover(); r != nil {
            log.Printf("panic: %v\n%s", r, debug.Stack())
        }
    }()
    work()
}()

Ловушки

  • recover в main не ловит панику в горутине.
  • Пустой recover прячет баг: логируй со стеком.
  • Выполнение не возвращается на строку после паники.
