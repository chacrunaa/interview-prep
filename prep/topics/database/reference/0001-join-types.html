Виды JOIN — шпаргалка

Роль JOIN в БД: собрать обратно данные, разнесённые по нормализованным таблицам, сопоставив строки по ключу.

JOINЧто возвращаетНа примере (3 users / 4 orders, 1 без заказов, 1 заказ-сирота)
INNERТолько строки, где есть совпадение с обеих сторон3 строки
LEFTВсе строки левой таблицы; справа NULL, если пары нет4 строки
RIGHTЗеркало LEFT — все строки правой таблицы4 строки
FULL OUTERВсе строки с обеих сторон; NULL там, где нет пары5 строк
CROSSДекартово произведение: N × M строк, без условия ON12 строк (3 × 4)
SELFТаблица соединяется сама с собой через два алиаса (иерархии)— (другой пример: employees/manager_id)
Ловушка: условие по правой таблице в WHERE (а не в ON) превращает LEFT JOIN в фактический INNER JOIN — NULL-строки не проходят фильтр (NULL > 400 не true).
