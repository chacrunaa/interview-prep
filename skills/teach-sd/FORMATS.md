# Форматы файлов prep/sd

Пути относительно `WS` (`~/personal/interview-prep/prep/sd`). Даты в формате YYYY-MM-DD.

## progress.md

Одна строка на тему карты курса, порядок строк совпадает с порядком карты.

```md
| урок | тема | уровень | последний раз | next |
|---|---|---|---|---|
| 01 | Клиент-сервер и архитектуры ИС | 2 | 2026-10-13 | 2026-10-20 |
| 01 | Балансировка нагрузки | - | | |
```

Уровни и интервалы - как в `skills/teach-go/FORMATS.md`: 0 - не знаю, 1 - узнаю, 2 - объясняю с подсказкой, 3 - объясняю сам без ошибок; `next` через 1/3/7/14/30 дней. `-` значит, что тема ещё не начата. Следующая тема для `next` - первая строка с `-`.

## journal/YYYY-MM-DD.md

Один файл на день, сессии дописываются в конец.

```md
# 2026-10-13

## 19:40 · next · 01 / Балансировка нагрузки

- **Прошли:** L4 vs L7, алгоритмы round robin / least connections (слайды 01:58-71).
- **Своими словами:** «L7 видит URL, поэтому может слать /api на одни сервера, а /static на другие» - верно.
- **Ошибки:** считал, что sticky sessions нужны всегда → разобрали, что это костыль для stateful.
- **ДЗ:** 01 - выдано.
- **Дальше:** next → «Кеширование».
```
