# Уроки из логов

Источник: `CT/audit/vacancy-history.md`, `CT/audit/TLDR.md` («Заметки»), `CT/reference/warriors-analysis.md`, карточки `pipeline/**/card.md`. Пополняй сюда, когда новый прогон показал новый класс ошибки (одна строка, дата, источник).

## Что стреляло

1. **Локация видна только в полном тексте вакансии и бьёт больнее пробелов в стеке.** nodi оказалась удалёнкой только для Латинской Америки, выяснилось после отклика (2026-09-30). Читать текст до сборки. Рыбой не снимается.
2. **Одна компания - несколько вакансий.** Andersen: три отклика, две вакансии - один проект, выставленный дважды. Customer.io, ClickHouse, TeamSnap, G2i - по две. Дубль по компании повторяет одну историю отклика: бери одну версию.
3. **Абсолютные цифры.** «100% полнота данных» без способа измерения вызывает «как измеряли». Ставить с оговоркой («по сверке с ... »), если способ есть в `facts.md`, иначе мягче или с `~`. Диапазоны без измерения («20-30%») выглядят хуже точной цифры.
4. **Senior в шапке, «Go-разработчик» везде.** Должность и тайтл совпадают. «Led» при руководителе в команде из 7 - вопрос.
5. **Один наниматель - один набор фактов во всех версиях.** Расходились: брокер [S2] (RabbitMQ / NATS), Mongo ([S2] / [S1]), Terraform ([S2] в nodi, канон [S1]), egress-сервис, npm-обёртка. Каноны привязок - `story.md`, раздел «Канон по старому разнобою». Resume одной компании у двух рекрутёров одного рынка сопоставят.
6. **Требование «6+ / 7+ лет».** Мастер впритык по годам, ранних мест нет (`[S0]`). Всплывало в nodi, go-react-fintech, x5. Закрывается гипотезой по годам (запись в карточке) и фуллстек-периодом без привязки к нанимателю; работодателей не выдумывать.
7. **Java / Spring.** Не заявлять никогда (решение 2026-09-29), даже при требовании. Заходить через Go-ветку («Go ИЛИ React+TS» и т.п.).
8. **Служебный мусор в тексте.** «только если реально делал, указать как именно» утекло в EN-версию. Любой комментарий на другом языке, `FIXME`, `[COMPANY]`, `[N]` - красный флаг.
9. **Кириллица и русские данные в EN-версии.** Для западных HR убирать (R-161, R-135); для русскоязычных команд за рубежом в чате не обсуждалось. Для hirify EN: русские города оставлять, российский номер - вопрос пользователю.

## Не использовать без решения пользователя

- egress / proxy-сервис (HTTP CONNECT, SOCKS5, десятки тысяч соединений) - только pinobyte, не определён слот.
- HTMX-админки - только nodi, деталь второго порядка, самому не поднимать.
- Keycloak и единый контур на ~25 проектов - без слота, «опасная зона» в `story.md`.
- NATS JetStream, event sourcing, CQRS как реальный опыт - только go-event-driven-nats, канон: брокер [S2] - RabbitMQ.
- Любые числа в `[N]`, которых нет в `facts.md` (см. примеры в `warriors-analysis.md`, раздел 5, шаг «числа для Syndicate»).

## Что прижилось

- Блок «Команда:» с реальными цифрами из `facts.md` под каждым местом - с x5, держать.
- Хронология ИИ: [S3] - ИИ нет, [S2] - Copilot + чат-модель, [S1] - Claude Code, мультиагентное ревью, агент на тестах. Не наращивать ИИ у [S3].
- Состав команд - реальные данные, не менять и не досочинять.
- ИИ весит как строка в навыках + один буллет, а не как отдельное место работы (warriors-analysis 2.1).
- Цифры с `~` читаются правдоподобнее круглых (R-053 и разбор Onur Karaman).
